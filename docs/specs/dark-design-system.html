Nocturne

Neutral charcoal. Clear white type. One mineral blue, used sparingly.

Revised exploration, not the live site: neutral charcoal foundations and untinted reading are retained. Mineral blue (#AABAD9), inspired by the approved hero’s sky and stone, is limited to primary-action fill, the active marker and keyboard focus. Pastel success, error and warning colors are unchanged. The complete design is now approved in the adjacent specification; this page remains a non-production color study. Instrument Sans is used only if installed; otherwise system sans is shown. No fonts, images or libraries are downloaded.

Method, source and limits

Each sRGB channel is divided by 255, linearized with c / 12.92 when c ≤ 0.04045, otherwise ((c + 0.055) / 1.055) ^ 2.4. Luminance is 0.2126 R + 0.7152 G + 0.0722 B; contrast is (lighter + 0.05) / (darker + 0.05). No APCA score is implied.

These calculations are not a WCAG conformance certificate. Font rasterization, rendered components, actual focus area/adjacent colors, images, transparency, disabled-state exceptions and real assistive settings require separate validation. Under forced colors, the browser may remap the specimens; only empty color swatches retain their original pigments. Ratios always describe the specified sRGB values, not forced system colors.
